# 🎵 Projeto_Musica

API REST para gerenciamento de músicas, bandas e integrantes.

Este repositório representa a evolução do projeto ao longo do tempo, contendo duas abordagens principais:

- 🔗 Versão com HATEOAS (hipermídia) finalizado,
- 📄 Versão com documentação via Swagger (versão final)

---

## 🚀 Tecnologias utilizadas

- Java
- Spring Boot
- Spring Data JPA
- HATEOAS
- Swagger / OpenAPI
- Maven

---

## ▶️ Como executar o projeto

### Pré-requisitos
- Java 17+
- Maven

### Passos

```bash
# Clonar repositório
git clone https://github.com/Waidemannm/Java.git

# Entrar na pasta
cd class-2ano-FIAP
cd projeto_musica

# Rodar aplicação
mvn spring-boot:run
```
